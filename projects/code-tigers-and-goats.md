As part of my sophomore project for ECE-296x, my team coded a digital version of the board game *Tigers and Goats (Huli Gutta)*. The project focused on implementing the rules and logic of the game so it could be played on a computer.

I contributed to the core game code in Python, including writing functions for generating valid moves, tracking game states, and adding an undo feature using a stack to store previous states. I also helped debug and test our code to make sure the game ran smoothly and followed the rules correctly.

This project gave me hands-on experience working on part of a larger-scale codebase and strengthened my skills in Python, problem-solving, and version control.
